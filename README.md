QuickBite 🍔
Your cravings, delivered.
QuickBite is a simple online food-delivery web app where customers can explore a menu, create an account, add dishes to a cart, place orders, and view their order history.
Project: College practical (PAT 4)
Status: Runs locally; a public live demo link has not been added yet.
✨ Explore QuickBite
Browse the menu — Explore food items, categories, and prices.
Create an account or log in — Use your own account or the demo account below.
Build your cart — Add dishes, change quantities, remove items, and see the total update.
Place an order — Enter a delivery address and submit your order.
Track your orders — Review your previous orders and their status.
Helpful feedback — Get clear messages when information is missing or needs correction.

🧭 How to use it
Open the website and browse the menu.
Add a few dishes to your cart.
Open the cart and adjust quantities if needed.
Create an account or log in.
Enter a delivery address and place your order.
Open My orders to see the order you placed.
🛠️ Built with
Frontend: HTML, CSS, JavaScript
Backend: Java
Database: Oracle Database
Database connectivity: JDBC
📌 Note
QuickBite is currently a local project rather than a hosted public website. To use it, the Java backend and Oracle database need to be running on the computer where the project is set up.
Made as a full-stack food-delivery application for a college practical.
