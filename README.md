# QuickBite 🍔
### Your cravings, delivered.

QuickBite is a full-stack food-delivery web application where customers can explore a menu, create an account, add dishes to a cart, place orders, and view their order history.

**Project:** College Practical (PAT 4)  
**Status:** Deployed and publicly accessible 🚀

## 🌐 Try QuickBite Live

**[🍔 Open QuickBite — Live Website](https://fooddeliveryapp-drab-ten.vercel.app/)**

Anyone with the link can access the deployed application through a web browser.

## ✨ Features

- 🍕 **Browse the menu** — Explore food items, categories, descriptions, and prices.
- 👤 **Login and registration** — Create an account or use the demo account, if available.
- 🛒 **Shopping cart** — Add dishes, change quantities, and remove items.
- 📦 **Place orders** — Enter a delivery address and submit an order.
- 🧾 **Order history** — View previous orders and their status.

## 🧭 How to Use QuickBite

1. Open the [live website](https://fooddeliveryapp-drab-ten.vercel.app/).
2. Browse the menu and explore the available dishes.
3. Add your favourite dishes to the cart.
4. Adjust quantities and review your total.
5. Log in or create an account.
6. Enter your delivery address and place your order.
7. Visit **My Orders** to view your order history.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java
- **Database:** PostgreSQL
- **Database Connectivity:** JDBC
- **Frontend Hosting:** Vercel
- **Backend and Database Hosting:** Render

## 🏗️ Application Architecture

The application uses a separate frontend, backend, and database:

- **Vercel** hosts the frontend.
- **Render** hosts the Java backend API.
- **PostgreSQL** stores customer, food item, order, and order-item data.

## 📌 Notes

- QuickBite is publicly accessible through the live website.
- The backend and database are hosted separately from the frontend.
- The first request may take longer if the backend service has been idle.
- Features such as registration, login, checkout, and order history depend on the backend and database being available.
