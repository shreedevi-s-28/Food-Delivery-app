# QuickBite 🍔
### Your cravings, delivered.

QuickBite is a simple online food-delivery web app where customers can explore a menu, create an account, add dishes to a cart, place orders, and view their order history.

**Project:** College practical (PAT 4)

## ✨ Features

- 🍕 **Browse the menu** — Explore food items, categories, and prices.
- 👤 **Login and registration** — Create an account or use the demo account.
- 🛒 **Shopping cart** — Add dishes, change quantities, and remove items.
- 📦 **Place orders** — Enter a delivery address and submit your order.
- 🧾 **Order history** — View your previous orders and their status.

## 🚀 Try QuickBite

## 🧭 How to use it

1. Open the website and browse the menu.
2. Add your favourite dishes to the cart.
3. Adjust quantities and review your total.
4. Log in or create an account.
5. Enter your delivery address and place your order.
6. Visit **My orders** to view your order.

## 🛠️ Technologies used

- HTML, CSS and JavaScript
- Java
- Oracle Database
- JDBC

## 📌 Note

QuickBite currently runs locally on the computer where it is set up. The Java backend and Oracle database must be running to use the application.
